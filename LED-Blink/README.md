# LED-Blink

## Beschreibung
Erstes Arduino-Projekt — eine LED blinkt im Sekundentakt. Grundlage für alle weiteren Embedded-Systems Projekte.

## Komponenten
- Arduino UNO
- 1x LED + 220Ω Widerstand

## Funktionsweise
1. Pin wird als OUTPUT definiert
2. LED wird abwechselnd auf HIGH und LOW gesetzt
3. delay() sorgt für die Wartezeit zwischen den Zuständen

## Was ich gelernt habe
- Grundstruktur eines Arduino-Sketches (setup/loop)
- digitalWrite() und delay()
- Aufbau einer einfachen Schaltung mit Vorwiderstand
- Installation der Arduino IDE und erstes Hochladen eines Sketches
